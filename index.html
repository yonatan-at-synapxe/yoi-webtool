                            Regex Cheat Sheet
                            Quick reference
                        
                        

                            
                            

                                
Anchors & Boundaries

                                
^Start of string / line

                                
$End of string / line

                                
\bWord boundary

                                
\BNon-word boundary

                            

                            
                            

                                
Character Classes

                                
.Any char (except newline)

                                
\dDigit [0–9]

                                
\wWord char [a-zA-Z0-9_]

                                
\sAny whitespace

                                
\D \W \SNegated shortcuts

                            

                            
                            

                                
Character Sets

                                
[abc]Any of a, b, or c

                                
[^abc]Not a, b, or c

                                
[a-z]Any lowercase letter

                                
[A-Z]Any uppercase letter

                                
[0-9]Any digit

                            

                            
                            

                                
Quantifiers

                                
*Zero or more (greedy)

                                
+One or more (greedy)

                                
?Zero or one (optional)

                                
*? +? ??Lazy (non-greedy) variants

                                
{n,m}Between n and m times

                            

                            
                            

                                
Groups

                                
(...)Capture group

                                
(?:...)Non-capturing group

                                
(?=...)Positive lookahead

                                
(?!...)Negative lookahead

                                
(?<=...) (?<!...)Lookbehind

                            

                            
                            

                                
Misc & Escapes

                                
|Alternation (OR)

                                
\nNewline character

                                
\tTab character

                                
\1 \2Backreference to group

                                
\.Escaped literal dot
